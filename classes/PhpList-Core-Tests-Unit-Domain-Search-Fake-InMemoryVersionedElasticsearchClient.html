InMemoryVersionedElasticsearchClient
in package
  • Application
implements ElasticsearchClientInterface

InMemoryVersionedElasticsearchClient.php : 15

Mirrors real Elasticsearch's `version_type: external_gte` semantics well enough to test revision-based conflict rejection without a live cluster: index()/delete() are no-ops whenever $revision is older than the revision last accepted for that document. The real vendor `Client` is `final`, so this is the only way to unit-test that ordering guarantee.

Interfaces

ElasticsearchClientInterface
Thin, mockable contract over the vendor Elastic\Elasticsearch\Client (which is `final` and exposes dozens of generated endpoint methods). Every method wraps vendor exceptions in SearchBackendUnavailableException, so nothing outside ElasticsearchClientAdapter depends on the vendor's exception hierarchy.
