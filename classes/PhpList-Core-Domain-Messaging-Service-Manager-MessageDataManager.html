storeMessageData()

MessageDataManager.php : 78

Stores a set of campaign settings the way phplist3's storemessage.php does for the campaign form.

public storeMessageData(Message $campaign, array<string, mixed> $data[, array<string|int, string> $checkboxes = [] ]) : void

Checkboxes that are not submitted when unchecked must be listed in $checkboxes: they are all reset to '0' first and then set again by $data when they were submitted. Every entry of $data is stored under its own name, booleans as '1' / '0'.

Only the names in WRITABLE_SETTINGS are accepted; nothing is stored when any other name is given. The campaign must already have an id, so a new campaign has to be flushed first.
