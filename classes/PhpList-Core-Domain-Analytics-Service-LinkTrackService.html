LinkTrackService
in package
  • Application

LinkTrackService.php : 22

Replaces the links of a campaign email with click-tracking links, like phplist3's sendemaillib.php.

Each distinct URL is stored once as a LinkTrackForward. The replacement link carries a token that identifies the forward, the campaign and the subscriber (see LinkTrackTokenService); LinkClickService resolves it again.
