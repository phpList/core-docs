BlacklistEmailCommand extends Command
in package
  • Application

BlacklistEmailCommand.php : 31

Equivalent of phplist3's `phplist -p blacklistemail -e email [-u uniqid] [-d date]`.

Looks the subscriber up by unique id or email. A known subscriber is blacklisted through SubscriberBlacklistService (flag, blacklist entry, history); an unknown address only gets a blacklist entry. Already blacklisted addresses are treated as success, as in legacy. Prints "OK " or "FAIL" so existing scripts that parse the legacy output keep working.

Deviation: the email is validated, and an unparsable --date is rejected instead of written to SQL.
