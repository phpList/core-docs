SubscriberLocaleResolver
in package
  • Application

SubscriberLocaleResolver.php : 18

Resolves the locale used for emails sent to a subscriber.

phplist3 has no language per subscriber or list. The language is a setting of the subscribe page (language_file in subscribepage_data, e.g. "german.inc"), and the subscriber keeps the page they used in subscribepage. This resolver maps that legacy language file to an ISO locale and falls back to the default.
