SubscriberHistoryRecordInterface
The read shape shared by the Doctrine-backed SubscriberHistory entity and the flat SubscriberHistoryReadModel built from Elasticsearch hits, so both SubscriberHistoryManager and SubscriberManager can read history rows without caring which backend produced them.
