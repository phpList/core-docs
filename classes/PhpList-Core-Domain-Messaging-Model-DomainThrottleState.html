DomainThrottleState
in package
  • Application
implements DomainModel

DomainThrottleState.php : 18

Per-domain send counters for a single fixed throttle window, persisted so that DomainRateLimiter enforces DOMAIN_BATCH_SIZE/DOMAIN_BATCH_PERIOD consistently across concurrent queue-processing workers instead of each worker keeping its own count.

Rows are read/written exclusively via DomainThrottleStateRepository's atomic UPDATE/INSERT statements, not through the entity manager's persist/flush.
